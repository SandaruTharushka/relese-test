ℹ️ How Updates Work / යාවත්කාල ක්‍රියාවලිය

              

                
Updates are distributed as Windows installers through GitHub Releases.

                
    
                  
  1. Click Check Now to query the latest release.
    2. 
                  
  2. If a newer version is available, review the release notes.
    3. 
                  
  3. Click Install Update to download and launch the installer.
    4. 
                  
  4. Your database, settings and license are automatically backed up first.
    5. 
                  
  5. The app closes, the installer upgrades the program files only.
    6. 
                  
  6. Your data is preserved — it lives in %LOCALAPPDATA%\Garage Management System.
    7. 
                

              

            


            
            

              
🔄 Recovery / ප්‍රතිසාධනය

              

                
If an update fails or causes problems, your data is safe:

                
    
                  
  • Pre-update backups are stored in %LOCALAPPDATA%\Garage Management System\backups\
    • 
                  
  • Each backup folder is named pre_update_YYYYMMDD_HHMMSS and contains the database, config and license files.
    • 
                  
  • To restore: use Settings → Backup → Restore, or copy supermart.db manually back to %LOCALAPPDATA%\Garage Management System\.
    •

☁️ Google Drive Setup Guide

    

      
To enable automatic Google Drive backups, you need to create a Google Cloud project:

      
    
        
  1. Go to console.cloud.google.com and create a new project
    2. 
        
  2. Enable the Google Drive API in the library
    3. 
        
  3. Go to Credentials → Create OAuth 2.0 Client ID
    4. 
        
  4. Choose Web Application as the type
    5. 
        
  5. Add Authorized Redirect URI:
    
          
            http://localhost:5000/api/backup/gdrive/callback
          
        
    6. 
        
  6. Copy the Client ID and Client Secret
    7. 
        
  7. Paste them in the settings above and click Save Credentials
    8. 
        
  8. Then click Connect Google Account and grant permission
    9. 
      

      

        💡 Folder ID (optional): Open a Drive folder and copy the ID from the URL:
        drive.google.com/drive/folders/THIS_IS_THE_ID
