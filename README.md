## Quick Start

### Step 1 — Run App
Double-click **`START.bat`**.

The app launches in a native desktop window (PySide6 Qt WebEngine) backed by a
local Flask server. The browser is never opened.

### Step 2 — First Run Database Creation
On first launch, SuperMart POS automatically:
- creates the SQLite database file,
- creates missing tables,
- runs safe column migrations for older databases,
- seeds only required system settings (no sample products or demo inventory),
- opens a secure first-run admin setup flow if no users exist yet.

Default database file:
- `supermart.db` in the app folder,
- or the path you set with `DATABASE_FILE` in `.env`.

### Step 3 — Login
On a brand-new install, the login screen becomes a **Create your first admin**
setup form. Enter your name, email, username, and a strong password.

## Developer Setup

### Required Python version

**Python 3.11** is the required and tested runtime for this project.
Python 3.12 is accepted as a secondary fallback; other versions are not tested.

### Create a virtual environment

```bat
py -3.11 -m venv venv
venv\Scripts\activate
```

### Install dependencies

```bat
pip install -r requirements.txt
```

### Run in development

```bat
python main.py
```

The desktop window opens automatically. The Flask server runs on
`http://127.0.0.1:5000` in a background thread.

### Remove legacy demo/sample data (existing dev databases)

If you used older development builds that inserted sample records, run:

```bat
python cleanup_demo_data.py --dry-run
python cleanup_demo_data.py --apply
```

- `--dry-run` shows what would be removed without deleting data.
- `--apply` removes only obvious demo/test/sample rows and known old seeded
  inventory barcodes/names.

### Build sell-ready desktop release (offline customer install)

```bat
build_desktop.bat
build_installer.bat
```

What this generates:
- `dist\SuperMartPOS.exe` → standalone desktop binary (no Python needed on customer PC)
- `release\SuperMartPOS.exe` → copied release binary
- `release\SuperMartPOS_Setup_v3.1.exe` → Inno Setup installer

Release structure:
- `/build` and `/dist` are generated by PyInstaller
- `/installer` holds `SuperMartPOS_Setup.iss`
- `/release` holds final customer deliverables

`BUILD.bat` remains as a quick alias for `build_desktop.bat`.

## Configuration (.env)

```env
# Default (recommended): SQLite zero-setup
DATABASE_FILE=supermart.db
ENABLE_DESTRUCTIVE_ADMIN_TOOLS=0

SMTP_USER=your@gmail.com
SMTP_PASS=app_password
```

Notes:
- `DATABASE_FILE` can be a file name like `supermart.db` or an absolute path.
- `ENABLE_DESTRUCTIVE_ADMIN_TOOLS` defaults to `0`; set it to `1` only for
  controlled support or development work, then restart the app.
- If you use a custom path, the target folder must be writable.
- Foreign key support is enabled automatically for SQLite connections.

## Installation Notes

### Windows desktop packaging
1. Install **Python 3.11** on the Windows build machine.
2. Create/refresh the virtual environment with `START.bat` or manually.
3. Build the one-file executable with `BUILD.bat` or:
   ```bat
   pyinstaller --clean --noconfirm SuperMartPOS.spec
   ```
4. The finished executable is written to `dist\SuperMartPOS.exe`.

#### Packaged-mode file locations
- `templates/` and `static/` are bundled into the EXE by PyInstaller.
- Fresh Windows installs store writable data in `%LOCALAPPDATA%\SuperMart POS`
  so `.env`, `supermart.db`, backups, and logs work without admin rights.
- If `.env` or `supermart.db` exist beside `SuperMartPOS.exe`, the app uses that
  portable folder instead (backward compatible).
- `DATABASE_FILE` in `.env` can override the default storage location.

#### Running the packaged EXE
1. Copy `dist\SuperMartPOS.exe` to the target Windows PC.
2. Optionally place a `.env` file beside it for a portable setup.
3. Double-click `SuperMartPOS.exe`.
4. On first run the app creates the SQLite database and opens the admin setup
   screen if no users exist yet.

#### Windows installer (Inno Setup)
1. Build the PyInstaller output first.
2. Open `SuperMartPOS_Setup.iss` in Inno Setup Compiler and compile.
3. The installer places the program in `Program Files\SuperMart POS` and stores
   runtime data in `%LOCALAPPDATA%\SuperMart POS` (database, backups, uploads, logos, exports, config, license).

### Browser mode (optional)
Use `START_WEB.bat` only for troubleshooting. The default launcher does not open
an external browser.

## Architecture

- Runtime database engine: SQLite via `DATABASE_FILE` in `.env`.
- Schema creation and safe column upgrades run automatically at startup.
- Desktop shell: PySide6 Qt WebEngine (Python 3.11+).
- Startup sequence: validate environment → start local Flask server → open Qt
  desktop window → shut down server on window close.
- Browser mode (`START_WEB.bat`) remains available for troubleshooting.
